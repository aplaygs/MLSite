# Как делать уроки английского

Правила для каждого урока раздела English. Образец — неделя 1 (`e01-1.html`, `e01-2.html`, `e01-3.html`, `e01-test.html`): если сомневаешься, сделай как там. Общие правила сайта (голос, токены, плавность, процесс) — в [`../GUIDE.md`](../GUIDE.md), про ML-уроки — [`STYLE.md`](STYLE.md).

## Для кого и как
- Влад, уровень A2, грамматика слабая. Цель — B1 → B2: собеседования и работа, фильмы, книги, поездки. Репетитора может не быть: урок должен заменять занятие.
- Упор — грамматика. Правило объясняется по-русски, коротко, через сравнение с русским: где русская привычка ломает английскую фразу.
- Каждое правило: формула → таблица форм (не шире 4 колонок) → когда употребляют → **«Ошибки русскоговорящих»** (пары ✗ → ✓) → упражнения. Без воды и без лингвистических терминов, которые не помогают говорить.
- Примеры — живые, про жизнь Влада (учёба, ML, Москва, друзья, поездки), уровня недели. Не выдумывай факты о Владе сверх известного: имя, Россия, студент, ML.
- Основа — юнит Cambridge Empower A2 этой недели (темы — в `.agents/data/en_plan.json`), но объяснение и упражнения — свои. Текст учебника не переписывать.

## Неделя
- План недели перед уроками — `PLAN-eNN.md` рядом (образец — [`PLAN-e02.md`](PLAN-e02.md)): что в каждой теме, лаборатории, упражнения, слова, состав теста. Уроки недели сразу заносятся в `en_lessons.json` со `"status": "planned"`.
- Урок 1 «Грамматика A» — главное правило юнита глубоко, плюс слова темы.
- Урок 2 «Грамматика B, слова и звук» — второе правило, слова, произношение (ударение, звуки).
- Урок 3 «Живой английский» — фразы на каждый день, письмо, и тема «Повторение» прошлых недель.
- Тест `eNN-test.html` — 20–25 вопросов, ~20% — повторение прошлых недель (с недели 2), 3–5 на слух (`say`), 5–7 с вводом (`type: "text"`). Повторение — отдельный «урок» в `lessons`: `{n: 4, file, label: "Повторение недели N", …}`, у его вопросов `file` — урок прошлой недели для ссылки «повторить» (образец — `e02-test.html`).
- Недели повторения (`kind: "review"`) — без нового: смешанные упражнения, ошибки, итоговый тест.

## Из чего состоит урок
1. Фрагмент без `<head>`: `<title>Урок N.K · Название</title>`, шрифты, `lesson.css`, `en.css`, `<style>` только для своих лабораторий, `<script src="/assets/nav.js">` и сразу `<script src="/assets/work.js">` (ответы упражнений сохраняются сами, у каждого `.ex` нужен `id`).
2. `topnav` (назад / «урок K из 3» / дальше), шапка: eyebrow `Неделя N · Юнит · урок K из 3 · X тем · ~60 минут`, `h1`, абзац, `.audio-note`, оглавление.
3. Темы `section.topic#tK`: eyebrow `Тема i из n · Грамматика|Слова|Произношение|Речь|Письмо|Повторение`, `h2` как в плане, `.tldr`, объяснение, таблица, выноски, упражнения `.ex`, `details.q` «Проверь себя», `.topic-check` с id темы.
4. Практика `#practice`: говорить вслух и писать, с образцом под `details`.
5. `#take` «В повторение» (`takeAway`: слова урока и 4–8 правил на заучку из шпаргалки), `#topics`, шпаргалка `#sheet` (6–10 пунктов, кнопка `#bCopy`), «Проверка без подсказок», ссылка на следующий урок.
6. **Конспект для Obsidian** — `<script type="text/markdown" id="md">`: заголовок `# 🇬🇧 Урок N.K · Название`, правила, таблицы (≤ 4 колонок), ошибки в `> [!warning]`, «Проверь себя» в сворачиваемых `> [!question]-`. Английские примеры курсивом, без обратных кавычек. `enplan.py build` кладёт его в `65_Английский/Уроки/` — Влад повторяет с телефона.
7. Скрипты: `lesson.js`, `en.js`, затем упражнения и `initLesson({topics:[[id, название], …]})`.

## Английский на странице
- Любая английская фраза — `<span class="say">…</span>`: клик читает голосом, второй клик сразу — медленнее. Для другой озвучки — `data-say="…"`.
- Подсветка: `.k` — бледно-абрикосовая (ключевая форма), `.k2` — голубая. Ошибки — `.pairs` / `.pair` с `.no` и `.yes`.
- Выноски: `.callout.ru` «Ошибки русскоговорящих», `.callout.mem` «Как запомнить», `.callout.trap` «Ловушка», `.callout.feel` — заметка.
- Диалоги — `.dlg` / `.dl` (`.dl.b` — второй собеседник).

## Упражнения (`assets/en.js`)
- `exGap` — пропуски (выбор `opts` или ввод; `say` — диктант; `exact` — важен регистр).
- `exBuild` — собрать фразу из плиток с лишними (`extra`), перевод с русского.
- `exSpot` — найди ошибку (`bad`, `fix`, `n`, `also`; `bad: -1` — ошибки нет).
- `exStress` — ударный слог. `exSort` — разложить по группам (звуки, a/an, окончания). `wordCards` — слова темы с тремя режимами.
- В каждой теме грамматики — минимум 3 упражнения разных видов, всего в уроке 8–12. Каждое `why` объясняет, а не повторяет ответ.
- Своя лаборатория — когда правило можно «покрутить»: конструктор (урок 1.1), перевёртыш вопроса (1.2), правка заглавных и проверка профиля (1.3). Впереди: шкала времён для present / past / future.

## Слова
- Слова урока (`const WORDS=[…]` → `wordCards`) и правила урока в конце попадают в блок «В повторение» (`takeAway`). Влад сам отмечает, что взять: кнопка добавляет в колоды `/words` и `/rules` и пересобирает «Словарь» и «Правила на заучку». Агент слова урока сам не добавляет. Правило-карточка: вопрос к себе («Когда у глагола -s?»), правило в 1–2 предложения, 1–3 примера, пара ✗ / ✓; id — `en.НН.У.rN`.

## Перед сдачей
- `en_lessons.json`: `{week, n, file, title, minutes, topics}`, тест — `{"kind": "test", "n": 4, …}`. Темы уроков недели = темы недели (это проверяет тест).
- `python3 .agents/scripts/enplan.py build` — конспекты и ссылки в файле недели.
- **`python3 .agents/scripts/lessoncheck.py check eНН-K.html` — 0 ошибок.** Скрипт ловит механику: ответа нет среди вариантов, номер в «найди ошибку» не на том слове, фразу не собрать из плиток, слоги не складываются, верный вариант теста не существует, ссылки и `$("id")` в никуда, нет галочки темы. Он же входит в `system.py lint`.
- **Смысл скрипт не проверяет — это ревью агента:** правило объяснено верно и по-русски понятно, английский естественный (как сказал бы носитель), каждое `why` объясняет, в «найди ошибку» ровно одна ошибка там, где задумано, нет двух правильных ответов по смыслу, уровень — неделя курса, факты о Владе не выдуманы.
- Пройти урок в браузере — не отвечая в настоящем уроке: работа в уроках, галочки и колоды сохраняются в данные Влада. Перехватить `fetch` POST (как с тестом) или снять копию данных и вернуть после.
- `python3 -m unittest discover -s .agents/tests`, `system.py lint`, строка в журнале изменений, `system.py commit`, `apps.py publish`.
