Пути к файлам: pathlib

7 мин

Зачем: пути строками («data/raw/» + name) ломаются на Windows и на лишнем слеше. pathlib собирает путь правильно на любом компьютере.

Путь — это объект Path. Части пути соединяют знаком /, как папки. У пути есть удобные свойства: имя, расширение, папка.

from pathlib import Path

raw = Path("data") / "raw"                 # data/raw — на Windows сам станет data\raw
f = raw / "studentInfo.csv"
f.exists()                                  # True / False
f.name, f.stem, f.suffix                    # 'studentInfo.csv', 'studentInfo', '.csv'
f.parent                                    # data/raw
list(raw.glob("*.csv"))                     # все csv в папке
Path("reports").mkdir(parents=True, exist_ok=True)   # создать, если нет, без ошибки
text = f.read_text(encoding="utf-8")        # прочитать файл целиком
Так это называютpathlib — стандартная библиотека; путь от корня диска — абсолютный, от текущей папки — относительный. Текущая папка программы — Path.cwd().

Пути — через Path и /. Папку для результатов — mkdir(parents=True, exist_ok=True).

Подробнее: путь от файла скрипта — главная ловушка ноутбуков и скриптов · 3 минуты

with: открыл — закрыл само

6 мин

Зачем: незакрытый файл может не дописаться на диск, а сотни открытых файлов роняют программу. with закрывает файл сам — даже если внутри случилась ошибка.

with open("data/raw/studentInfo.csv", encoding="utf-8") as f:
    header = f.readline()          # первая строка
    for line in f:                 # дальше по одной строке — не грузим весь файл в память
        ...
# здесь файл уже закрыт

with open("reports/log.txt", "a", encoding="utf-8") as f:   # "w" — перезаписать, "a" — дописать в конец
    f.write("готово\n")

encoding="utf-8" пиши всегда: без него русские буквы на Windows превращаются в кракозябры. with работает не только с файлами — так же открывают соединение с базой или ставят таймер.

Так это называютконтекстный менеджер (context manager) — объект, который умеет «войти» и «выйти» (__enter__ и __exit__); with гарантирует выход.

Файлы — только через with и с encoding="utf-8". "w" стирает файл, "a" дописывает.

Подробнее: большие файлы, свой контекстный менеджер, несколько файлов · 3 минуты
  • for line in f: читает по одной строке — так можно пройти файл на 10 ГБ, держа в памяти одну строку. f.read() загрузит его целиком.
  • Два файла сразу: with open(a) as src, open(b, "w") as dst:.
  • Битая кодировка (UnicodeDecodeError): узнай, в какой кодировке файл (старые русские — cp1251), или errors="replace", чтобы не упасть.
  • Свой контекстный менеджер — функция с yield и декоратором. Например, таймер:
from contextlib import contextmanager
import time

@contextmanager
def timer(name):
    t = time.perf_counter()
    yield                                   # здесь выполняется тело with
    print(f"{name}: {time.perf_counter() - t:.2f} с")

with timer("загрузка"):
    rows = load_rows()

Декораторы подробно — неделя 5. Пока достаточно понимать: всё до yield — «вход», после — «выход».

json и csv

8 мин

Зачем: csv — таблицы (как OULAD), json — всё остальное: настройки, ответы API, отчёты. Читать и писать оба надо уметь без pandas — он не всегда под рукой.

import csv, json

with open("data/raw/studentInfo.csv", encoding="utf-8") as f:
    rows = list(csv.DictReader(f))       # каждая строка — словарь {столбец: значение}
rows[0]["final_result"]                   # 'Pass'
rows[0]["studied_credits"]                # '240' — СТРОКА! для чисел — int(...)

report = {"rows": len(rows), "pass": sum(r["final_result"] == "Pass" for r in rows)}
with open("reports/summary.json", "w", encoding="utf-8") as f:
    json.dump(report, f, ensure_ascii=False, indent=2)   # словарь → текст; ensure_ascii=False — русский читаемо

with open("reports/summary.json", encoding="utf-8") as f:
    back = json.load(f)                   # текст → словарь

Запомни пару имён: load / dump — с файлом, loads / dumps (s — string) — со строкой.

Так это называютпревратить объект в текст — сериализация; обратно — десериализация. CSV — comma-separated values.

csv.DictReader — строки как словари, но все значения — строки. json: load/dump с файлом, loads/dumps со строкой.

  • csv-модуль правильно понимает кавычки: "Москва, Россия" — одно поле, хоть внутри и запятая. Простой line.split(",") такое ломает.
  • json: ключи словаря всегда становятся строками ({1: "a"} → {"1": "a"}), кортежи — списками, None — null, True — true. NaN в стандарте json нет.
  • JSON Lines (.jsonl) — по одному json-объекту на строку. Так пишут логи и большие наборы: можно читать построчно.

Взглянуть на файл из терминала

10 мин

Зачем: на сервере нет Jupyter, а файл на 2 ГБ не откроешь в редакторе. Первые строки, число строк и быстрый подсчёт — за секунду прямо в терминале.

head -5 файлпервые 5 строк (по умолчанию 10)
tail -n 3 файлпоследние 3 строки
wc -l файлсколько строк
less файллистать большой файл (q — выйти; в тренажёре нет)
команда1 | команда2пайп: вывод первой — на вход второй
… > файл, … >> файлзаписать вывод в файл / дописать в конец
tail -f train.logследить за файлом вживую: новые строки появляются сами (Ctrl+C — выйти). Так смотрят лог обучения
… 2> errors.txt, … > out.txt 2>&1ошибки идут отдельным потоком: 2> пишет только их, 2>&1 — ошибки туда же, куда обычный вывод
cut -d, -f5взять 5-й столбец, разделитель — запятая
sort | uniq -cотсортировать и посчитать одинаковые строки

Пайпы — как конвейер: grep Withdrawn файл | wc -l — «отбери строки с Withdrawn, и посчитай, сколько их». Каждая команда делает одно маленькое дело.

Так это называютпайп (pipe, |) и перенаправление (redirect, > и >>); у каждой программы есть вход — stdin и выход — stdout.

head, tail, wc -l — первый взгляд на данные. | соединяет команды, > пишет в файл.

Подробнее: less, ключи grep, sort по столбцу и подвох с кавычками · 3 минуты
  • less файл: пробел — страница вниз, /Pass — найти, n — следующее совпадение, q — выйти. В отличие от cat, не вываливает весь файл.
  • grep -i — без учёта регистра, -v — строки без совпадения, -c — сразу число вместо строк, -n — с номерами строк.
  • sort -t, -k5 — сортировать по 5-му столбцу, разделитель — запятая; -n — как числа, -r — по убыванию.
  • wc -l считает символы переноса строки: если в конце файла переноса нет, последнюю строку не посчитает.
  • Подвох: в настоящем OULAD значения в кавычках ("Pass"), а в некоторых csv внутри полей бывают запятые — тогда cut -d, режет неправильно. Для быстрого взгляда терминал хорош, для точного подсчёта — Python.
  • > /dev/null — выбросить вывод («чёрная дыра»), например команда 2> /dev/null — спрятать ошибки.

sorted с key: сортировка по чему угодно

7 мин

Зачем: «топ-5 студентов по баллам», «файлы от новых к старым», «слова по длине» — везде нужна сортировка не по самому элементу, а по какому-то его свойству.

У sorted есть параметр key — функция, которая для каждого элемента говорит, по чему сравнивать. Короткую функцию на месте пишут через lambda: lambda r: r["score"] — «возьми у строки r её score».

students = [{"name": "Аня", "score": 91}, {"name": "Иван", "score": 78}, {"name": "Оля", "score": 85}]

sorted(students, key=lambda r: r["score"], reverse=True)   # по баллам, от больших
sorted(["pandas", "ml", "numpy"], key=len)                   # ['ml', 'numpy', 'pandas']
sorted(students, key=lambda r: (-r["score"], r["name"]))     # по баллам вниз, при равенстве — по имени

nums = [3, 1, 2]
nums.sort()            # сортирует САМ список и возвращает None
new = sorted(nums)     # возвращает НОВЫЙ список, старый не трогает
Так это называютlambda — анонимная (безымянная) функция в одну строку; сортировка Python стабильная: равные элементы сохраняют прежний порядок.

sorted(…, key=…, reverse=True) — новый список. list.sort() — на месте и возвращает None.

Подробнее: itemgetter, min и max с key, сортировка без учёта регистра · 2 минуты
  • from operator import itemgetter; sorted(rows, key=itemgetter("score")) — то же, что lambda, чуть быстрее и короче.
  • key есть не только у sorted: max(rows, key=lambda r: r["score"]) — лучший студент, min(files, key=len).
  • sorted(names, key=str.lower) — без учёта регистра (иначе «Zoe» окажется раньше «anna»: заглавные идут первыми).
  • Сортировка — O(n log n). Если нужны только 5 лучших из миллиона — heapq.nlargest(5, rows, key=...) быстрее (куча — неделя 8).

Сделай сам: первый отчёт по данным

15 мин

Всё из урока в одном скрипте: Path, with, csv, Counter, sorted с key и json. Данные — маленький файл, который скрипт сам создаёт, поэтому ничего скачивать не надо. В неделе 3 этот же скрипт запустишь на настоящем OULAD — поменяется только путь.

Код · 15 минут

Скрипт summary.py

  1. Создай data/students.csv из строки SAMPLE ниже: папку — через mkdir(parents=True, exist_ok=True), файл — через write_text.
  2. Прочитай его через with и csv.DictReader. Посчитай итоги через Counter и топ-3 студентов по studied_credits через sorted с key (не забудь int — в CSV всё строки).
  3. Сохрани отчёт в reports/summary.json и выведи его.
SAMPLE = """id_student,final_result,studied_credits
11391,Pass,240
28400,Pass,60
30268,Withdrawn,60
31604,Pass,60
32885,Fail,60
38053,Pass,60
45462,Pass,120
45642,Distinction,120
52130,Withdrawn,90
53025,Fail,30
"""

Готово, когда в отчёте {"Pass": 5, "Withdrawn": 2, "Fail": 2, "Distinction": 1}, а первым в топе — 11391 (240 кредитов).

Решение
import csv, json
from collections import Counter
from pathlib import Path

DATA = Path("data") / "students.csv"
OUT = Path("reports")

DATA.parent.mkdir(parents=True, exist_ok=True)
DATA.write_text(SAMPLE, encoding="utf-8")

with open(DATA, encoding="utf-8") as f:
    rows = list(csv.DictReader(f))

results = Counter(r["final_result"] for r in rows)
top = sorted(rows, key=lambda r: int(r["studied_credits"]), reverse=True)[:3]

OUT.mkdir(parents=True, exist_ok=True)
report = {"rows": len(rows), "results": dict(results),
          "top_credits": [r["id_student"] for r in top]}
with open(OUT / "summary.json", "w", encoding="utf-8") as f:
    json.dump(report, f, ensure_ascii=False, indent=2)
print(report)

Без int сортировка шла бы по строкам: «90» оказалось бы больше «240», потому что «9» > «2».

На собеседовании

Так спрашивают на отборах на стажировку. Сначала ответь вслух сам, потом открой ответ.

СобеседованиеКак прочитать файл на 10 ГБ, если памяти 8 ГБ?

Не грузить целиком: читать построчно через with open(...) as f: for line in f, или кусками (в pandas — read_csv с chunksize). Обрабатывать и сразу агрегировать, а не держать всё в памяти.

СобеседованиеЗачем with при работе с файлами?

Это контекстный менеджер: при выходе из блока файл гарантированно закрывается, даже если внутри было исключение. Без этого можно потерять незаписанные данные или упереться в лимит открытых файлов.

СобеседованиеКак быстро посмотреть на большой файл на сервере?

head и tail — начало и конец, wc -l — число строк, less — листать, grep — найти строки, tail -f — следить за логом в реальном времени. Через пайп можно посчитать значения: cut | sort | uniq -c.

  1. pathlib: Path("data") / "raw" / "x.csv"; .exists(), .name, .stem, .suffix, .parent, .glob("*.csv"); mkdir(parents=True, exist_ok=True).
  2. with open(…, encoding="utf-8") as f — файл закроется сам. "w" — перезаписать, "a" — дописать.
  3. csv.DictReader — строки как словари, значения — строки. json: load/dump — файл, loads/dumps — строка; ensure_ascii=False.
  4. Терминал: head -5, tail -n 3, wc -l; | — конвейер, > / >> — в файл; cut -d, -f5 | sort | uniq -c — подсчёт значений.
  5. sorted(…, key=lambda r: r["score"], reverse=True) — новый список; list.sort() — на месте и None.
  6. Яндекс: стажировка — анкета, Контест, технические секции; ШАД — бесплатно, 2 года, отбор по математике и алгоритмам.
