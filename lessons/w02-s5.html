Пути к файлам: pathlib

7 мин

Зачем: пути строками («data/raw/» + name) ломаются на Windows и на лишнем слеше. pathlib собирает путь правильно на любом компьютере.

Путь — это объект Path. Части пути соединяют знаком /, как папки. У пути есть удобные свойства: имя, расширение, папка.

from pathlib import Path

raw = Path("data") / "raw"                 # data/raw — на Windows сам станет data\raw
f = raw / "studentInfo.csv"
f.exists()                                  # True / False
f.name, f.stem, f.suffix                    # 'studentInfo.csv', 'studentInfo', '.csv'
f.parent                                    # data/raw
list(raw.glob("*.csv"))                     # все csv в папке
Path("reports").mkdir(parents=True, exist_ok=True)   # создать, если нет, без ошибки
text = f.read_text(encoding="utf-8")        # прочитать файл целиком
Так это называютpathlib — стандартная библиотека; путь от корня диска — абсолютный, от текущей папки — относительный. Текущая папка программы — Path.cwd().

Пути — через Path и /. Папку для результатов — mkdir(parents=True, exist_ok=True).

with: открыл — закрыл само

6 мин

Зачем: незакрытый файл может не дописаться на диск, а сотни открытых файлов роняют программу. with закрывает файл сам — даже если внутри случилась ошибка.

with open("data/raw/studentInfo.csv", encoding="utf-8") as f:
    header = f.readline()          # первая строка
    for line in f:                 # дальше по одной строке — не грузим весь файл в память
        ...
# здесь файл уже закрыт

with open("reports/log.txt", "a", encoding="utf-8") as f:   # "w" — перезаписать, "a" — дописать в конец
    f.write("готово\n")

encoding="utf-8" пиши всегда: без него русские буквы на Windows превращаются в кракозябры. with работает не только с файлами — так же открывают соединение с базой или ставят таймер.

Так это называютконтекстный менеджер (context manager) — объект, который умеет «войти» и «выйти» (__enter__ и __exit__); with гарантирует выход.

Файлы — только через with и с encoding="utf-8". "w" стирает файл, "a" дописывает.

json и csv

8 мин

Зачем: csv — таблицы (как OULAD), json — всё остальное: настройки, ответы API, отчёты. Читать и писать оба надо уметь без pandas — он не всегда под рукой.

import csv, json

with open("data/raw/studentInfo.csv", encoding="utf-8") as f:
    rows = list(csv.DictReader(f))       # каждая строка — словарь {столбец: значение}
rows[0]["final_result"]                   # 'Pass'
rows[0]["studied_credits"]                # '240' — СТРОКА! для чисел — int(...)

report = {"rows": len(rows), "pass": sum(r["final_result"] == "Pass" for r in rows)}
with open("reports/summary.json", "w", encoding="utf-8") as f:
    json.dump(report, f, ensure_ascii=False, indent=2)   # словарь → текст; ensure_ascii=False — русский читаемо

with open("reports/summary.json", encoding="utf-8") as f:
    back = json.load(f)                   # текст → словарь

Запомни пару имён: load / dump — с файлом, loads / dumps (s — string) — со строкой.

Так это называютпревратить объект в текст — сериализация; обратно — десериализация. CSV — comma-separated values.

csv.DictReader — строки как словари, но все значения — строки. json: load/dump с файлом, loads/dumps со строкой.

Взглянуть на файл из терминала

10 мин

Зачем: на сервере нет Jupyter, а файл на 2 ГБ не откроешь в редакторе. Первые строки, число строк и быстрый подсчёт — за секунду прямо в терминале.

head -5 файлпервые 5 строк (по умолчанию 10)
tail -n 3 файлпоследние 3 строки
wc -l файлсколько строк
less файллистать большой файл (q — выйти; в тренажёре нет)
команда1 | команда2пайп: вывод первой — на вход второй
… > файл, … >> файлзаписать вывод в файл / дописать в конец
cut -d, -f5взять 5-й столбец, разделитель — запятая
sort | uniq -cотсортировать и посчитать одинаковые строки

Пайпы — как конвейер: grep Withdrawn файл | wc -l — «отбери строки с Withdrawn, и посчитай, сколько их». Каждая команда делает одно маленькое дело.

Так это называютпайп (pipe, |) и перенаправление (redirect, > и >>); у каждой программы есть вход — stdin и выход — stdout.

head, tail, wc -l — первый взгляд на данные. | соединяет команды, > пишет в файл.

sorted с key: сортировка по чему угодно

7 мин

Зачем: «топ-5 студентов по баллам», «файлы от новых к старым», «слова по длине» — везде нужна сортировка не по самому элементу, а по какому-то его свойству.

У sorted есть параметр key — функция, которая для каждого элемента говорит, по чему сравнивать. Короткую функцию на месте пишут через lambda: lambda r: r["score"] — «возьми у строки r её score».

students = [{"name": "Аня", "score": 91}, {"name": "Иван", "score": 78}, {"name": "Оля", "score": 85}]

sorted(students, key=lambda r: r["score"], reverse=True)   # по баллам, от больших
sorted(["pandas", "ml", "numpy"], key=len)                   # ['ml', 'numpy', 'pandas']
sorted(students, key=lambda r: (-r["score"], r["name"]))     # по баллам вниз, при равенстве — по имени

nums = [3, 1, 2]
nums.sort()            # сортирует САМ список и возвращает None
new = sorted(nums)     # возвращает НОВЫЙ список, старый не трогает
Так это называютlambda — анонимная (безымянная) функция в одну строку; сортировка Python стабильная: равные элементы сохраняют прежний порядок.

sorted(…, key=…, reverse=True) — новый список. list.sort() — на месте и возвращает None.

Скрипт summary.py

  1. Файл src/oulad_risk/summary.py: путь к данным — через Path, файл — через with и csv.DictReader.
  2. Посчитай итоги курса через Counter (урок 2.3) и топ-5 студентов по studied_credits через sorted с key (не забудь int).
  3. Сохрани отчёт в reports/summary.json (папку создай через mkdir). Закоммить: feat: add data summary.
Решение
import csv, json
from collections import Counter
from pathlib import Path

RAW = Path("data") / "raw" / "studentInfo.csv"
OUT = Path("reports")

with open(RAW, encoding="utf-8") as f:
    rows = list(csv.DictReader(f))

results = Counter(r["final_result"] for r in rows)
top = sorted(rows, key=lambda r: int(r["studied_credits"]), reverse=True)[:5]

OUT.mkdir(parents=True, exist_ok=True)
report = {"rows": len(rows), "results": dict(results),
          "top_credits": [r["id_student"] for r in top]}
with open(OUT / "summary.json", "w", encoding="utf-8") as f:
    json.dump(report, f, ensure_ascii=False, indent=2)
print(report)

Папку reports/ можно добавить в .gitignore — её всегда можно пересоздать скриптом.
