zip, enumerate и распаковка

8 мин

Зачем: в коде про данные постоянно надо идти по двум спискам сразу или знать номер строки. Эти три приёма заменяют неудобные for i in range(len(...)).

Распаковка — раздать значения по именам одной строкой. enumerate — идти по списку и сразу знать номер. zip — идти по нескольким спискам парами.

a, b = 1, 2
a, b = b, a                          # обмен без третьей переменной
first, *rest = [10, 20, 30]          # first = 10, rest = [20, 30]

names = ["Аня", "Иван", "Оля"]
for i, name in enumerate(names, start=1):
    print(i, name)                   # 1 Аня, 2 Иван, 3 Оля

scores = [91, 78]
for name, score in zip(names, scores):
    print(name, score)               # только 2 пары: zip останавливается на самом коротком!
list(zip(names, scores, strict=True))  # ValueError — если длины обязаны совпадать
Так это называютраспаковка (unpacking), *rest — «звёздочка собирает остальное». zip и enumerate возвращают итераторы — поэтому печатают через list(...).

zip молча обрезает по самому короткому. Нужен номер — enumerate, а не range(len()).

collections: Counter и defaultdict

8 мин

Зачем: «посчитать, сколько раз встречается» и «разложить по группам» — две задачи, которые в данных делаешь каждый день. Для них есть готовые инструменты.

Counter(words)посчитать, сколько раз каждый элемент: Counter("abca") → {'a': 2, 'b': 1, 'c': 1}
.most_common(3)три самых частых
defaultdict(list)словарь, который для нового ключа сам заводит пустой список
dequeочередь: быстро добавлять и забирать с обоих концов
from collections import Counter, defaultdict

results = ["Pass", "Fail", "Pass", "Withdrawn", "Pass"]
Counter(results).most_common(1)      # [('Pass', 3)]

groups = defaultdict(list)           # курс → список имён
for name, course in [("Аня", "ML"), ("Иван", "SQL"), ("Оля", "ML")]:
    groups[course].append(name)      # с обычным dict тут был бы KeyError на первом же ключе
# {'ML': ['Аня', 'Оля'], 'SQL': ['Иван']}

Посчитать — Counter. Сгруппировать — defaultdict(list). Очередь — deque.

Как словарь находит ключ за один шаг

12 мин

Зачем: «что происходит, когда пишешь d["Аня"] = 5» — классический вопрос собеседования. И отсюда же правило «ключ должен быть неизменяемым».

Представь гардероб на 8 крючков. Чтобы не искать пальто по всем крючкам, номер крючка вычисляют из самого пальто: по нему считают число, и это число говорит, куда вешать. Потом, чтобы найти, считают то же число — и идут сразу к нужному крючку.

  • Это число — хеш: hash("Аня"). Из хеша получают номер ячейки (например, остаток от деления на число ячеек).
  • Если ячейка занята другим ключом — это коллизия: Python пробует следующую ячейку по своему правилу и сравнивает ключи через ==.
  • Когда таблица заполняется примерно на две трети, Python делает её больше и раскладывает всё заново.
Лаборатория · положи ключи в таблицу

Учебный хеш: сумма кодов букв, остаток от деления на 8. У настоящего Python хеш сложнее, но логика та же. Попробуй «ab» и «ba» — у них одинаковый хеш.

    Так это называютхеш-таблица; ключом может быть только хешируемый (hashable) — неизменяемый — объект: число, строка, кортеж. Поиск, вставка, удаление — O(1) в среднем.

    Хеш ключа → номер ячейки → сразу туда. Список ключом быть не может: изменится — изменится хеш.

    list или set: почему in бывает медленным

    7 мин

    Зачем: одна замена списка на множество ускоряет фильтр данных с часов до секунд. В тесте недели 1 это был вопрос про фильтр миллиона строк.

    x in список — Python идёт по списку с начала и сравнивает с каждым элементом. Элементов n — до n сравнений. x in множество (или в словаре) — считает хеш и сразу смотрит в нужную ячейку, как в гардеробе.

    Two Sum: меняем память на скорость

    8 мин

    Зачем: задача №1 на LeetCode и частый первый вопрос алгоритмической секции. Сама идея «запоминай увиденное в словаре» решает десятки задач.

    Задача: в массиве найти два числа, которые в сумме дают target, и вернуть их номера.

    В лоб: перебрать все пары — два вложенных цикла, O(n²). Умно: идём один раз. Для каждого числа x считаем, какое нужно ему в пару: need = target − x. Если need уже встречали — ответ найден. Если нет — запоминаем x в словаре «число → номер».

    def two_sum(nums, target):
    seen = {}                        # число → его номер
    for i, x in enumerate(nums):
        need = target - x
        if need in seen:             # O(1): проверка в словаре
            return [seen[need], i]
        seen[x] = i
    return None
    Лаборатория · Two Sum по шагамnums = [4, 1, 7, 3, 9], target = 10
    Так это называютприём hash map («хеш-мапа») / «запоминай увиденное»; обмен памяти на время: O(n) времени и O(n) памяти вместо O(n²) и O(1).

    Two Sum: один проход, need = target − x, словарь «число → номер». O(n) и O(n).
