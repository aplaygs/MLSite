Имя — это ярлык, а не коробка

12 мин

Зачем: половина «странных» багов в Python — из-за того, что два имени смотрят на один и тот же список. Поменял через одно — поменялось и в другом. В тесте недели 1 на этом были два вопроса.

Представь, что объекты — это вещи на полке, а имена переменных — ярлыки на ниточках. Запись b = a не копирует вещь: она вешает второй ярлык на ту же самую вещь.

Дальше всё зависит от вещи. Список, словарь, множество можно менять на месте — и это увидят все ярлыки. Число, строку, кортеж поменять нельзя: «изменение» создаёт новый объект, и ярлык перевешивается на него.

Лаборатория · карта памяти по шагам
b = aвторой ярлык на тот же объект — не копия
b = a.copy()новая вещь — копия списка (или list(a), a[:])
b.append(3), b += [3]меняют список на месте — видно через все ярлыки
b = b + [3]создаёт новый список и перевешивает только b
def f(acc=None)список по умолчанию — только так: [] в def создаётся один раз на все вызовы
Так это называютимена — ссылки на объекты; список и словарь — изменяемые (mutable), число, строка, кортеж — неизменяемые (immutable). Ловушка с acc=[] — mutable default argument.

b = a — тот же объект. Нужна копия — a.copy(). Список по умолчанию — None, а внутри новый [].

Типы: числа, строки и дробные, которые врут

8 мин

Зачем: в данных постоянно приходят числа строками («5» из CSV), а сравнение дробных через == ломает проверки в ML-коде.

Пять типов, которые встречаются везде: int (целое), float (дробное), str (строка), bool (True / False) и None — «значения нет». Узнать тип — type(x).

  • 7 / 2 → 3.5 — обычное деление всегда даёт float. 7 // 2 → 3 — целая часть. 7 % 2 → 1 — остаток.
  • "5" + "1" → "51" — строки склеиваются. Сначала превратить в число: int("5") + 1 → 6.
  • Дробные хранятся неточно, потому что компьютер считает в двоичной системе: 0.1 + 0.2 → 0.30000000000000004. Поэтому дробные сравнивают с допуском.
0.1 + 0.2 == 0.3               # False!
import math
math.isclose(0.1 + 0.2, 0.3)   # True — равны с маленьким допуском
abs((0.1 + 0.2) - 0.3) < 1e-9  # то же самое руками
Так это называютчисла с плавающей точкой (floating point, стандарт IEEE 754); превращение типов — приведение (casting): int(), float(), str().

Дробные через == не сравнивают — только math.isclose. Из CSV всё приходит строками.

== или is, и что Python считает «ложью»

8 мин

Зачем: проверка if n_missing: молча путает «пропусков ноль» с «значения нет». В данных это классическая ошибка.

== спрашивает: одинаковые ли значения? is спрашивает: это одна и та же вещь (один объект)? Два разных списка [1, 2] равны по ==, но is даёт False.

На практике is нужен ровно для одного: проверить None — x is None, x is not None. Всё остальное — через ==.

Python умеет ставить в if что угодно. Считаются ложью: 0, 0.0, "", [], {}, None, False. Всё остальное — правда, даже "0" и [0].

n_missing = 0
if n_missing:                 # 0 — ложь: сюда не зайдём, хотя число есть
    ...
if n_missing is not None:     # правильно: «значение задано», даже если это 0
    ...
Так это называют== — равенство (equality), is — тождество (identity); то, что Python считает ложью, — falsy, остальное — truthy.

None проверяют только через is. «Пустое» и «ноль» — тоже ложь, поэтому if x: — не проверка на None.

Где живёт имя: внутри функции и снаружи

8 мин

Зачем: ошибка UnboundLocalError и «почему функция не видит мою переменную» — частые вопросы на первой работе и на собеседовании.

У функции своя комната. Имена, которым внутри функции что-то присваивают, живут только в этой комнате. Прочитать имя снаружи функция может, а вот присвоить ему — уже нет: присваивание сразу делает имя «своим», внутренним.

Ищет Python по порядку: сначала в своей функции, потом во внешней функции (если одна внутри другой), потом в файле, потом среди встроенных (len, print).

total = 10
def show():
    print(total)          # читать снаружи можно → 10

count = 0
def add():
    count = count + 1     # UnboundLocalError: count внутри — своя, а ей ещё ничего не присвоили

def add(count):           # правильно: получить через параметр…
    return count + 1      # …и вернуть через return
count = add(count)
Ловушка: функция помнит имя, а не значение

Функция, созданная в цикле, смотрит на переменную цикла в момент вызова, а не в момент создания. fs = [lambda: i for i in range(3)] — все три функции вернут 2: когда их вызвали, цикл уже закончился и i = 2. Починка: lambda i=i: i — значение сохраняется в параметре.

Так это называютобласть видимости (scope); порядок поиска — LEGB: Local → Enclosing → Global → Built-in. Функция, которая помнит внешние имена, — замыкание (closure).

Данные в функцию — через параметры, наружу — через return. global почти никогда не нужен.

Срезы: кусок строки или списка

7 мин

Зачем: срезы — это «первые 5 строк», «последние 3 недели», «каждый второй элемент». В pandas и NumPy (недели 4–5) они работают так же.

Запись s[start:stop:step]: с start включительно, до stop не включая, с шагом step. Пропущенное — значит «с начала», «до конца», «шаг 1». Отрицательные номера считают с конца: -1 — последний.

  • s[:3] — первые три · s[-3:] — последние три · s[::2] — каждый второй · s[::-1] — задом наперёд.
Лаборатория · покрути срез

Так это называютсрез (slice); у строк, списков и кортежей одинаковый синтаксис. Срез списка — копия: a[:].

stop не включается: s[1:5] — это 4 элемента, с 1-го по 4-й.

Две функции без ловушек

  1. safe_mean(values): среднее списка, а для пустого списка — None. Проверь: safe_mean([]), safe_mean([0, 0]) — во втором случае должен быть 0, а не None.
  2. add_score(score, scores=None): добавляет оценку в список и возвращает его. Вызови дважды без второго аргумента — списки не должны «слипаться».
Решение
def safe_mean(values):
    if not values:              # пустой список — ложь
        return None
    return sum(values) / len(values)

m = safe_mean([0, 0])
if m is not None:               # не «if m:» — иначе 0 потеряется
    print("среднее", m)

def add_score(score, scores=None):
    if scores is None:
        scores = []             # новый список на каждый вызов
    scores.append(score)
    return scores

Итог

  1. Ярлыки: b = a — тот же объект. Копия — a.copy(). append и += меняют список на месте, b = b + [3] — новый список.
  2. Список по умолчанию: def f(acc=None): if acc is None: acc = [].
  3. Типы: 7 / 2 = 3.5, 7 // 2 = 3, 7 % 2 = 1. "5" + "1" = "51" — из CSV всё строки.
  4. Дробные: 0.1 + 0.2 != 0.3 — сравнивай math.isclose.
  5. is — только для None. Ложь: 0, 0.0, "", [], {}, None, False. if x: — не проверка на None.
  6. Функции: присваивание внутри — своё имя. Данные — через параметры и return. Функция помнит имя, а не значение.
  7. Срезы: [start:stop:step], stop не включается; [::-1] — задом наперёд.
